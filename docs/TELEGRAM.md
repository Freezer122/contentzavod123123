# Telegram-бот

В hotfix V1.5 бот постоянно работает на VPS отдельной службой `content-factory-telegram.service`, роль `bot`. Команды `/start`, `/ping`, `/status`, `/accounts`, `/queue` доступны владельцу из allowlist. Постоянный worker остаётся DRY_RUN, завод PAUSED; запуск бота не включает публикации. В `/queue` отображаются timestamps и интервал пост → CTA, если они известны. Настройка, приёмка и ограничения — в [отчёте V1.5](HOTFIX_V1_5_REPORT.md).

Задайте TELEGRAM_BOT_TOKEN и allowlist TELEGRAM_ALLOWED_IDS. Управление доступно только разрешённым пользователям в личном чате. Используется один long-polling процесс на токен. `/start` открывает меню; `/help` — команды.

## Отдельные посты — основной режим

«Создать публикацию → Отдельный пост каждому аккаунту». Выберите аккаунт, отправьте его английский текст либо ссылку X, подтвердите права. Повторите для остальных аккаунтов. Нажмите «Подготовить назначенные посты», проверьте результаты и подтвердите очередь. Не назначенные аккаунты не получают публикаций.

Если отправить текст напрямую, бот сначала запросит права и выбор одного аккаунта. `/reuse SOURCE_ID` позволяет выбрать материал из библиотеки. Один исходник на несколько аккаунтов допускается в дополнительном режиме BROADCAST.

## Общий исходник

«Создать публикацию → Один исходник нескольким аккаунтам». Отправьте материал, подтвердите права, выберите аккаунты. COMMON — одна адаптация; PER_ACCOUNT — пакет вариантов по стилям. Готовые результаты берутся из кэша. Кнопка «Перегенерировать» явно разрешает новый запрос; в COMMON она обновляет весь выбранный общий пакет.

## CTA и аккаунты

«Аккаунты → аккаунт → Редактировать CTA». Отправьте текст, затем HTTPS-ссылку. После текста и ссылки нажмите «Сохранить CTA». Снимок фиксируется при первом старте: ожидающие задачи получают новый CTA, начатые и завершённые сохраняют историю. На каждом аккаунте одна запись CTA, которую можно включать/отключать. Целевое время комментария — 20 секунд после submit поста; отправка разрешается после надёжного подтверждения его URL. При позднем подтверждении дополнительной двадцатисекундной паузы нет.

Команды: `/cta ACCOUNT_ID текст`, `/cta_url ACCOUNT_ID https://...`, `/cta_template ACCOUNT_ID TEMPLATE_ID`. Шаблон копируется в индивидуальный CTA. `/cta_off ACCOUNT_ID` отключает CTA, `/cta_on ACCOUNT_ID` включает. Для остановки постов приостановите аккаунт.

Добавление и стили сохраняются: `/account JSON`, `/style STYLE_ID JSON`, `/account_style ACCOUNT_ID STYLE_ID`, `/example STYLE_ID текст`. Новые аккаунты приостановлены. Проверьте авторизацию перед включением.

## Очередь

Цель — 120 минут между первым и последним стартом выбранных аккаунтов, для десяти — 12-минутные слоты и резерв до конца двухчасового окна. Для одного аккаунта интервал не нужен. Отклонение и причина задержки сохраняются. Ограничение платформы или простой могут отодвинуть фактический результат.

`/cancel JOB_ID`, `/run JOB_ID`, `/reschedule JOB_ID ISO_UTC`, `/resume_job JOB_ID` сохраняют защиту состояний. `/interval` больше не задаёт случайный интервал. Пауза запрещает новые отправки; уже начатая отправка может завершиться.

COMMENT_FAILED не делает пост неуспешным. `/retry_comment JOB_ID` допускается только при известной ошибке до отправки. UNCERTAIN требует ручной проверки; `/verify JOB_ID URL` и `/verify_comment JOB_ID URL` фиксируют найденный результат без повторной отправки.

## Аналитика

В аналитике доступны прежние фильтры/метрики, CSV, «Рейтинг контента» с общим возрастом измерения и «Retention Telegram». Темы/форматы/хуки для будущих публикаций: `/tag SOURCE_ID {"topic":"Риск","format":"Разбор","hook":"Вопрос"}`. `/timezone Europe/Moscow` задаёт часовой пояс пользователя.

Для канала задайте TELEGRAM_CHANNEL_ID, назначьте боту права администратора. `/invite ACCOUNT_ID` создаёт или возвращает одно постоянное аккаунтное приглашение и redirect. `/link ACCOUNT_ID https://t.me/...` возвращает тот же tracking URL. postId не принимается: атрибуция только на уровне аккаунта. Без подтверждённой ссылки источник вступления остаётся неизвестным.

D7/D30 показывают только зрелые когорты; неизвестное членство не превращается в ноль. Проверка через Bot API требует прав и зашифрованного ID, сохранённого при получении события. Исторический хеш V1.0 не позволяет восстановить Telegram user ID.

## Шаблоны, оценки и диагностика

«Шаблоны Threads» позволяет создать/изменить шаблон, добавить примеры, закрепить на аккаунте и посмотреть статистику. Снятие доступно в карточке аккаунта. `/template_edit ID {"name":"...","instruction":"..."}` меняет название и инструкцию. Рейтинг текущей версии требует минимум 10 сопоставимых замеров.

Под черновиком нажмите «Хорошо» или «Плохо». Оценку можно изменить. «Качество генераций» показывает примеры и процент одобрения без дополнительных обращений к модели.

«Система → Диагностика DRY_RUN» проверяет ошибки только на MockBrowserProvider. Реальные профили в этом режиме не проверяются и не запускаются. Переход к LIVE — отдельный согласованный этап.
