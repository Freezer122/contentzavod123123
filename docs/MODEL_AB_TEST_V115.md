# V1.15 — Sol vs Terra A/B

Дата: 21 ноября 2026, МСК. Эксперимент `v115-sol-terra-01`, статус READY. Запущен после сохранённой успешной приёмки generation hotfix.

## Выборка и метод

Запрошено 20 исходников, фактически доступны 4: русский язык, точная дата, возраст не более 48 часов, строгий торговый контекст. Повторный READ_ONLY-поиск достиг действующего суточного лимита сессий; ограничение не повышалось ради A/B. Старые/нерелевантные материалы для заполнения выборки не добавлялись.

Для каждой пары заморожены одинаковые исходник, настройки голоса, prompt и человеческие примеры. Sol `gpt-6.2-sol`, reasoning low; Terra `gpt-6.1-terra`, reasoning none; Responses API, max_output_tokens 1024 для обеих. Одна генерация на вариант, невалидные ответы сохранены без автоповтора. Оценщик LLM не использовался.

Позиции A/B перемешаны и сохранены; кнопки выбора A/B/равно/оба плохие и курсор продолжаются после перезапуска. Полные варианты доступны файлом. Карточки оценки не содержат разрешений на публикацию. До оценки всех доступных пар Telegram скрывает сопоставление моделей и детальную статистику, чтобы не раскрыть позиции.

Это реальный usage ответов API, не оценка по длине текста. Нулевые reasoning tokens также получены из usage; параметр low всё равно передан Sol. Время отдельных запросов: 1.607–4.826 с. Независимый атомарный лимит эксперимента $0.25 / 40 запросов действует совместно с общими бюджетами и резервом; UNKNOWN сохраняет резервирование и останавливает новые вызовы.

Один вариант Sol сохранён NEEDS_EDIT из-за проверки финансового идентификатора (`$83`/IPO); повторной генерации не было. Остальные семь прошли существующий форматный gate. Формальная валидность не доказывает достоверность исходной новости: пример с IPO требует отдельной оценки контекста.

На момент подготовки отчёта пользовательских оценок 0/4. Победителя нет, сравнение маленькое; вывод о качестве и автоматическая смена production-модели не выполнялись. Модели остались POST=Sol, REPLY/BIO=Terra. Разметка серьёзности/юмора предварительная эвристическая, не экспертная оценка.

Открыть: Telegram → «Тест моделей» → «Sol vs Terra». При поступлении голосов статистика рассчитывается из сохранённых голосов, а не выдумывается.
