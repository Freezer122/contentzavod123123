# ИИ и кэш адаптаций V1.2

Задайте LLM_BASE_URL, LLM_API_KEY, LLM_MODEL, температуру, лимит токенов, цены за миллион токенов и лимиты расходов. API должен поддерживать POST /chat/completions и возвращать текст и usage. Потоковая генерация не используется.

Основная инструкция адаптирует X-подачу к разговорному Threads: одна мысль, минимум жаргона, без выдуманного личного опыта. Восемь шаблонов и персональные стили учитываются в кэше и истории.

Один исходник — один запрос на перевод и адаптацию. Невалидный ответ не запускает второй запрос автоматически: отредактируйте черновик или нажмите «Перегенерировать». Перед отправкой проверяются длина, русский текст, абзацы, эмодзи, запрещённые выражения, числа и тикеры. Семантика остаётся предметом предпросмотра.

ACCOUNT_SPECIFIC готовит только явно назначенные пары исходник → аккаунт. BROADCAST COMMON использует один общий текст; PER_ACCOUNT объединяет отсутствующие в кэше стили в один JSON-запрос. Одинаковые настройки используют один готовый результат. Инструкция короткая; примеры ограничены двумя фрагментами. Подробности ключа кэша и поведения COMMON — в [UPDATE_V1_1.md](UPDATE_V1_1.md).

Смена исходника, модели, инструкции или стиля меняет ключ кэша. Ручная перегенерация обходит кэш и создаёт новую версию. Ручные редакции сохраняются как отдельные версии. Обычная публикация, переход между профилями, планирование, аналитика, рейтинг и проверка членства не обращаются к LLM.

Перед запросом транзакционно резервируется оценка максимальной стоимости. Для пакета резерв учитывает суммарный лимит вывода, до 16 000 токенов. После ответа сохраняются usage и стоимость. Неизвестный результат API удерживает резерв: провайдер мог списать деньги. Это оценка, а не сверенный биллинг. При достижении лимита новые генерации останавливаются, администратор получает уведомление.

Для X-ссылки нужен X_BEARER_TOKEN; без него отправляйте английский текст. Повторный исходник находится в библиотеке через `/search` и `/reuse`. Новые материалы получают REVIEW, а очередь требует OWN или PERMITTED.

В демонстрации работает фиксированный русский тестовый генератор. Он проверяет интерфейс и расходует ноль внешних токенов; качество реального перевода им не подтверждается.

👍/👎 сохраняют оценку и происхождение результата без нового LLM-запроса и без автоматического разрешения публикации. Общий процент учитывает последнюю оценку каждого текста. Пакетные токены помечены SHARED_REQUEST и общим request ID; их нельзя суммировать повторно по вариантам. Ручная правка — MANUAL_EDIT с нулевыми новыми токенами. Для старых данных без provenance модель и токены неизвестны. Подробности: [отчёт перед запуском](PRELAUNCH_REPORT.md).
