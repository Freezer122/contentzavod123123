## Статусы и Telegram

`approvalStatus`: DRAFT, APPROVED, REJECTED. `executionStatus`: WAITING, PUBLISHING, PUBLISHED, UNCERTAIN, FAILED. Для совместимости прежний SENDING остаётся внутренним барьером; на экране ему соответствует PUBLISHING. PREVIEWED — историческая/диагностическая отметка, не публикация.

После одобрения бот пишет «Ответ одобрен, но ещё не опубликован», показывает аккаунт, исходный URL, точный текст, время одобрения, оба режима и причину ожидания. Доступны «Опубликовать сейчас», изменение, DRY_RUN, отклонение и возврат. Для PUBLISHED показывается permalink, для UNCERTAIN — только read-only проверка результата, без повторной отправки.

В меню добавлены «Одобренные ответы» и «Стиль ответов». Диагностика разделяет черновики, одобренные тексты, ожидание отправки, опубликованные и UNCERTAIN. Служебные тестовые записи не завышают счётчик ручных одобрений.

Изменение текста увеличивает версию, снимает одобрение и делает старую неисполненную задачу недействительной. Старое разрешение не подходит к новому хэшу/версии; нужно новое одобрение. История сохраняется. Существующие одобренные тексты не сокращаются при миграции или смене стиля.

## Безопасная разовая отправка

«Опубликовать сейчас» запускает только READ_ONLY-preflight: проверку выбранной задачи, аккаунта, исходного поста, редактора и точного текста, без submit. После успешной проверки появляется карточка с финальными кнопками подтверждения/отмены и разрешением на пять минут.

Разрешение связано с accountId, replyJobId, исходным URL, хэшем, версией текста и Telegram user ID. Для реального выполнения одновременно нужны:

1. Адресное разрешение оператора для этого job ID и пользователя с действующим сроком.
2. Финальное подтверждение владельца в Telegram для свежего preflight.

По умолчанию адресное разрешение **отсутствует**. Будущие параметры `ONE_SHOT_REPLY_JOB_ID`, `ONE_SHOT_REPLY_USER_ID`, `ONE_SHOT_REPLY_EXPIRES_AT` сейчас пусты. Их можно задавать только после отдельного разрешения пользователя на конкретное LIVE-действие. Глобальные BROWSER/ENGAGEMENT режимы и factoryPaused менять ради одного ответа не требуется.

Перед submit разрешение потребляется **в одной транзакции с SENDING/PUBLISHING**. Повтор, другой пользователь, изменённый текст/URL, истечение срока или отмена отклоняются. Leases, один browser-slot, ручное одобрение, ACTIVE-аккаунт, включённый engagement, дневные лимиты, интервалы и приоритет собственных публикаций/CTA сохраняются.

Адресный путь может разрешить только выбранный ответ при общей PAUSED/DRY_RUN. Он не разрешает лайки, другую задачу или backlog. Даже глобальный LIVE сам по себе больше не активирует накопленную очередь engagement: автоматическая публикация оставлена OFF. Для будущей автоматики нужны отдельная реализация, проверка правил Threads/ограничений аккаунта и безопасная точка начала без старого backlog.

Playwright подтверждает точный текст, собственный аккаунт, родительскую публикацию и permalink. Неоднозначность после барьера переводится в UNCERTAIN, без автоматического retry. Read-only проверка UNCERTAIN может подтвердить существующий результат; отсутствие найденного ответа не разрешает повторную отправку.

## Terra V1.11

Новый стабильный промпт: `terra-comments-v1.11`, модель `gpt-6.1-terra`, reasoning none. Один запрос на выбранную публикацию, без оценочной LLM, истории переписки и автоматических платных исправлений.

По умолчанию «Короткие»: ориентир 60–220 символов, до трёх предложений, разговорный русский. «Очень короткие» — максимум 140 символов и два предложения; «Развёрнутые» — максимум 360 и три. Небольшой содержательный ответ не дополняется искусственно ради минимального числа символов.

После TextNormalizer проверяются язык, размер, предложения, формат, новые числа/тикеры/URL, реклама, шаблонное вступление и повтор ответа под другой публикацией. Если результат не подходит, он сохраняется как NEEDS_EDIT или DECLINED с причинами и реальным расходом. Перегенерация — только явная команда. Полную смысловую корректность оператор проверяет по предпросмотру; отдельная LLM для оценки не вызывается.

Один настоящий запрос выполнен к сохранённому [посту про покупку акций](https://www.threads.com/@drenderyga/post/DZ61mFVCEKD). Результат доставлен в Telegram, оставлен неодобренным черновиком READY:

> главное, чтобы рынок не узнал, когда решишь продать, а то вдруг сразу отскочит

**78 символов, одно предложение. Input: 226 tokens. Output: 27 tokens. Стоимость: $0.000361.** Стоимость рассчитана из API usage по ранее проверенному Standard-тарифу; это не считывание платёжного баланса. В V1.11 выполнен ровно один новый платный запрос, без повтора/оценки. Общий учтённый расход на момент финальной проверки — $0.007185, включая предыдущие тесты и генерации пользователя. Предупреждение $3, накопительный предел $5 и существующие бюджеты сохранены.
