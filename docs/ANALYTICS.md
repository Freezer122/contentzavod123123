# Аналитика V1.2

История Threads сохраняет просмотры, лайки, ответы, репосты, цитирования и подписчиков. Контрольные снимки: 1/6/24/48/72/168 часов; 48 часов сохранены для совместимости. Регулярные снимки продолжаются ежечасно, для постов старше 30 дней — ежедневно. Сборщик работает без ИИ.

Снимок хранит фактическое время и источник. Недоступная метрика — NULL. Поздний замер не выдаётся за первый час: допускается окно 1:00–1:15; для остальных контрольных точек — первый час после целевой даты. Рейтинг исключает поздние или неизвестные значения.

Настройте INSIGHTS_ACCESS_TOKEN и `/insights ACCOUNT_ID NUMERIC_API_USER_ID`. API ID поста определяется по permalink среди собственных постов. Публикация выполняется только через браузер, Insights используется только для чтения. Доступ к данным ваших аккаунтов и формат ответов требуют внешней приёмки. Единый token поддерживает только разрешённые ему аккаунты; отдельные OAuth-токены разных владельцев пока не реализованы.

Сохраняются два режима: накопительные просмотры постов, опубликованных за период, и прирост просмотров между доступными снимками периода. Снимки одного поста не суммируются повторно. При отсутствии базового измерения старого поста прирост неизвестен. Отчёт показывает покрытие; частичные суммы не выдаются за полные.

После V1.1 ссылки и подписки атрибутируются аккаунту. Постовые клики и вступления — NULL; отдельный пост не получает чужие аккаунтные подписки. CR_view рассчитывается для режима прироста просмотров за период, сопоставимого с аккаунтным потоком вступлений. В режиме когорты опубликованных постов этот CR неизвестен. CR_click использует отдельные подтверждённые вступления и клики за период.

Content Performance Rating сравнивает посты по одинаковому возрасту 1/6/24/72/168 часов и считает средние/медианные результаты тем и форматов. Исходник, итог, признаки текста и дата публикации сохраняются; разность подписчиков Threads относится к аккаунту в соответствующем измеряемом окне. Подробнее: [UPDATE_V1_1.md](UPDATE_V1_1.md).

Постоянный `/r/CODE` записывает клик и перенаправляет на сохранённую HTTPS-ссылку t.me. Сохраняется HMAC посетителя, а не сырой IP/UA. Уникальность приблизительная; автоматические предпросмотры тоже могут создавать клики. За Nginx задайте TRUST_PROXY=127.0.0.1,::1 и перезаписывайте X-Forwarded-For как в конфигурации.

Telegram-когорты учитывают отдельные вступления, повторные вступления, подтверждённые выходы, неизвестный источник, D7/D30, Retention и Churn. Пропущенное или позднее измерение не считается отпиской. Подробные знаменатели и время проверки доступны в `/api/retention`; панель Telegram по умолчанию показывает всю историю наблюдений. ID для Bot API хранится зашифрованным. TRACKING_HASH_SECRET требуется сохранять при обновлениях.

В V1.2 добавлены лайки/ответы/репосты в сопоставимых карточках, топ/антитоп по 24 часам, средние/медиана/максимум/минимум и динамика. Основной рейтинг шаблонов требует минимум 10 известных своевременных измерений текущей версии. Старые версии остаются в истории. До порога статистика предварительная; отсутствующие значения остаются NULL.

Подтверждённые выходы отдельного аккаунта учитываются по ранее наблюдаемым когортам с подтверждённым источником. Неизвестный источник не присваивается аккаунту. Подписки и клики не приписываются шаблону или отдельному посту.
